# 🚀 Cryptocurrency Liquidity Prediction

A machine learning project to **predict cryptocurrency liquidity** and analyze **market stability** using historical price and volume data.

## 🔍 Features

* Data preprocessing & feature engineering
* ML model training for liquidity prediction
* Visualization of trends and performance
* Easy-to-run Python scripts

## 🧰 Tech Stack

* Python
* Pandas, NumPy
* Scikit-Learn
* Jupyter Notebook

## ▶️ How to Run

```bash
git clone https://github.com/omchaudhari602/Cryptocurrency-Liquidity-Prediction-for-Market-Stability.git
cd Cryptocurrency-Liquidity-Prediction
pip install -r requirements.txt
python save_model.py
```
